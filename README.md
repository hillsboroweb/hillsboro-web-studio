# Hillsboro Web Studio

Static website source for Hillsboro Web Studio. The site uses the studio's forest green and gold branding.

GitHub Pages publishes the repository root from the `main` branch. The site is built with plain HTML and CSS and has no build step.

## Current homepage

The homepage uses the HWS cobalt palette, Aurora Bars, and Liquid Glass. The page is plain HTML, CSS, and JavaScript with no build step.

The visual direction is adapted from [unlumen UI components](https://ui.unlumen.com/components). Liquid Glass is vendored under its MIT license in `vendor/liquid-glass/`.
